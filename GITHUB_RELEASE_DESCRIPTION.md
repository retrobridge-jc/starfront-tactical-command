# STARFRONT: TACTICAL COMMAND v1.0 — 1984 Edition

**Lost in 1984. Rediscovered in 2026.**

Take command of the cruiser Vanguard in a Commodore 64 BASIC V2 space strategy adventure. Explore the frontier, defend colonies, fight tactical battles, manage damage and supplies, and keep your Captain’s Log. Includes original SID title music.

**Play:** Attach `STARFRONT.D64` in VICE as drive 8, then type `LOAD "STARFRONT",8` followed by `RUN`. Or load the `.PRG` directly.

**Included:** Tested D64 and PRG, source listing, manual, quick reference, and screenshots.

**Testing:** V1.0 RC1 passed ten gameplay tests in VICE; the corrected disk image also loaded in VICE. Physical C64 testing is not yet confirmed.
